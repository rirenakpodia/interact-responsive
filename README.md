# interact-responsive

Mobile-first, responsive rebuilds of interactive lookbooks and site modules designed by Rire Nakpodia (Rire Design).

The original desktop-era versions live in [rirenakpodia/interact](https://github.com/rirenakpodia/interact). Each rebuild keeps the same folder name as its original, so the links line up:

| Piece | Original | Responsive |
|---|---|---|
| Aéropostale Shorts (Girls) | [interact/Aero_Shorts_Girls](https://rirenakpodia.github.io/interact/Aero_Shorts_Girls/) | [interact-responsive/Aero_Shorts_Girls](https://rirenakpodia.github.io/interact-responsive/Aero_Shorts_Girls/) |

Images in the rebuilds were AI upscaled (Real-ESRGAN) from the original web assets.
